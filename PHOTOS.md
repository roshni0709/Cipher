# About the product photos

Real retailer product photos are not included in this repository because they
belong to their brands. The files in `pricematch/data/photos/` are generated
placeholders so the app runs from a fresh clone. Regenerate them any time:

    python make_placeholders.py

Photo search works best with real photos, so for a full demo add your own
photos using the same filenames (`<product-id>.jpg`, `<product-id>-2.jpg`, ...).
